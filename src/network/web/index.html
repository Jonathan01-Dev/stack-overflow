Configuration de votre nœud Archipel

🤖 Clé API Gemini

La clé sera stockée dans le fichier .env du nœud. Obtenez votre clé sur Google AI Studio.

📡 Comment rejoindre l'équipe
Sur le même réseau local (Wi-Fi / Hotspot / Câble) :
Chaque membre doit lancer : python archipel.py --port 7777 --web-port 8080

La découverte est automatique via Multicast UDP. Les nœuds se trouvent en quelques secondes.

Ports à autoriser : UDP 6000 (découverte) · TCP 7777 (communication)
🔑 Générer une nouvelle identité

Crée un nouveau fichier node.key avec une clé Ed25519 unique.

python archipel.py gen-key
